# AMVA - Associação Master Vale do Aço

Aplicativo Android oficial da AMVA.

**Nome exibido no Android e no instalador:** AMVA - Associação Master Vale do Aço

O aplicativo usa a versão publicada do sistema AMVA e mantém a integração atual com Supabase. Não requer Node.js para instalação ou uso.

## Gerar o APK

No GitHub, abra **Actions → Build AMVA APK → Run workflow**. O APK de teste será publicado como artefato da execução.
